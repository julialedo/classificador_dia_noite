# Classificação Dia e Noite com Visão Computacional
Trabalho da matéria de Aprendizagem de Máquina.

Projeto de classificação de imagens externas como **"dia"** ou **"noite"** usando duas abordagens distintas de Machine Learning.

## Objetivo

Analisar imagens de ambientes externos capturadas sob diferentes condições de iluminação e classificá-las automaticamente como dia ou noite.


## Abordagens

Abordagem 1 — Transfer Learning com CNN (MobileNetV2)

Abordagem 2 — Machine Learning Clássico com Random Forest


## Resultados (teste com 30 imagens)

CNN (MobileNetV2) - 27/30 = 90% 
Random Forest - 29/30 = 96,67%



## Dataset

Dataset utilizado para treinamento: [Unpaired Day and Night cityview images](https://www.kaggle.com/datasets/) — disponível no Kaggle.
